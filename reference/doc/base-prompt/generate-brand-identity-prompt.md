# Build the Brand Identity from the Approved Design System and Visual Benchmark

Use the **`brand` skill** as the primary skill for this task.

The project already has:

1. An approved `DESIGN-SYSTEM.md`
2. An approved full-page visual benchmark
3. An approved mobile visual benchmark, if available
4. An established visual direction that has already passed review

These materials are **approved and must not be redesigned**.

Your task is to extract, formalize, strengthen, and document the **brand identity system** that naturally emerges from the approved design system and visual benchmark.

This is a **brand systemization phase**, not another visual exploration phase.

---

# 1. Primary Objective

Create a complete brand identity for the premium beauty salon based on the visual language that has already been approved.

The brand identity must explain:

> Who this brand is, how it should feel, how it should communicate, and how its visual identity should remain recognizable across different contexts.

The resulting brand identity must be fully compatible with the existing design system and approved visual benchmark.

Do not create a competing visual language.

Instead:

**Extract → Formalize → Clarify → Strengthen → Document**

the identity that already exists.

---

# 2. Source-of-Truth Hierarchy

Use the following hierarchy whenever making a brand decision:

```text
APPROVED VISUAL BENCHMARK
            +
     DESIGN-SYSTEM.md
            ↓
    EXISTING VISUAL DNA
            ↓
      BRAND IDENTITY
```

The approved visual benchmark demonstrates **how the brand actually looks and feels**.

`DESIGN-SYSTEM.md` defines the **rules that create that experience**.

The new brand identity must explain the **strategic and expressive identity behind those rules**.

If a recommendation from the `brand` skill conflicts with either approved source:

**The approved visual benchmark and DESIGN-SYSTEM.md win.**

Do not override them.

# 5. Brand Context

The brand represents a **premium high-end beauty salon**.

The salon should be perceived as:

* Premium
* Sophisticated
* Comfortable
* Calm
* Intimate
* Contemporary
* Artistic
* Confident
* Refined
* Highly curated
* Personal
* Exclusive without being intimidating

The salon is not simply selling beauty treatments.

It is offering a carefully curated experience around:

**beauty + craftsmanship + ritual + atmosphere + personal care**

# 6. Brand Positioning

Define a clear brand positioning.

Explain:

### Category

What kind of beauty business is this?

### Market Position

Where does it sit relative to:

* mainstream salons
* premium salons
* luxury salons
* wellness brands
* boutique beauty studios

### Value Proposition

Why should customers choose this salon despite premium pricing?

### Emotional Value

How should customers feel before, during, and after interacting with the brand?

# 31. Brand Consistency vs. Creative Freedom

Clearly separate:

## FIXED BRAND ELEMENTS

Elements that should remain highly consistent.

Examples:

* core typography
* primary palette
* photography philosophy
* voice
* core spacing character
* brand personality

## FLEXIBLE BRAND ELEMENTS

Elements that may vary.

Examples:

* editorial compositions
* image crops
* campaign typography
* visual storytelling
* certain secondary colors

## EXPERIMENTAL ELEMENTS

Areas where creative direction can evolve while remaining recognizable.

This distinction is important because the brand should be consistent without becoming visually repetitive.

# 37. Important Final Constraint

This phase is about **formalizing the brand identity**.

Do not redesign the website.

Do not create a new visual benchmark.

Do not create another design system.

Do not replace approved typography or colors.

Do not introduce a competing art direction.

Do not proceed into website implementation.

The workflow is:

```text
APPROVED DESIGN-SYSTEM.md
            +
APPROVED VISUAL BENCHMARK
            ↓
       BRAND SKILL
            ↓
EXTRACT EXISTING BRAND DNA
            ↓
FORMALIZE BRAND STRATEGY
            ↓
FORMALIZE VERBAL IDENTITY
            ↓
FORMALIZE VISUAL IDENTITY
            ↓
     BRAND-GUIDELINES.md
            ↓
      CONSISTENCY REVIEW
            ↓
           STOP
```

The final `BRAND-GUIDELINES.md` must strengthen and explain the identity that already exists rather than replacing it.

The goal is:

> **Turn the approved visual experience into a coherent, recognizable, and reusable brand identity without losing the character that made the original design direction successful.**
