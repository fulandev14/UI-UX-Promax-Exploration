# Create Navigation + Hero Visual Benchmark

Create a high-fidelity **Navigation + Hero Section visual benchmark** for the website.

## Source of Truth

Before generating anything, carefully read and analyze:

* `BRAND-GUIDELINES.md`
* `DESIGN-SYSTEM.md`

Treat both documents as authoritative sources of truth.

If any previously approved section visual benchmarks exist, use them as continuity references.

**Use all previously approved section visual benchmarks as continuity references. They are not templates to copy. Study them to preserve the established typography, color behavior, imagery treatment, spacing rhythm, grid logic, visual density, and overall art direction while creating a composition appropriate to the current section.**

Do not redesign the brand.

Do not create a new design system.

Do not introduce a competing art direction.

This phase is strictly for **visual design exploration and visual benchmark generation**.

Do not generate frontend code or technical implementation.

---

## Objective

Create a premium opening experience that immediately establishes the visual identity and quality bar for the entire website.

The Hero should feel closer to the opening spread of a luxury beauty or fashion editorial than a conventional landing page.

Focus on:

* Art Direction
* Minimal Swiss discipline
* Asymmetric Layout
* Editorial Grid / Magazine composition
* Bold Typography
* Cinematic Imagery
* deliberate negative space
* sophisticated visual hierarchy
* premium navigation treatment
* strong image cropping
* typography/image relationships

Avoid the conventional:

**Centered headline → paragraph → two buttons → hero image**

Explore a deliberately art-directed composition.

The navigation should visually belong to the Hero rather than appearing as an unrelated generic website header.

Include representative:

* brand/logo
* navigation
* booking action
* headline
* supporting message
* primary CTA
* cinematic imagery

The emotional impression should communicate:

**premium + sophisticated + intimate + contemporary + artistic + calm + confident**

Typography must function as a major visual element.

Photography should feel like:

**Luxury Beauty Campaign × Fashion Editorial × Boutique Hospitality**

Use the colors, typography, spacing, imagery, grid, and visual principles already established by the source documents.

---

## Output

Generate a **high-fidelity visual benchmark image** of the complete Navigation + Hero section.

Prioritize:

**Art Direction → Composition → Typography → Imagery → Hierarchy → Atmosphere**

Do not generate code.

Do not proceed to another section.

Stop after generating the visual benchmark for review and approval.
